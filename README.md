# NetSentinel Packet Analyzer

NetSentinel is a Python-based network packet analyzer designed for traffic monitoring, packet inspection, and basic DoS detection support. The project provides a graphical interface built with PyQt6 for real-time packet visualization and network analysis.

## Features

* Real-time packet capture and monitoring
* Packet detail inspection
* Hexdump visualization
* I/O graph visualization
* Multi-protocol analysis (TCP, UDP, DNS, HTTP)
* Basic DoS detection support using AI concepts

## Technologies Used

* Python
* PyQt6
* Scapy
* Random Forest
* Matplotlib
